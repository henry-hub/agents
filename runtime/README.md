# Skills Runtime

Skills 的执行引擎——负责加载、沙箱化运行、编排 Skills 组合。

## 定位

Runtime 是 Skills 的"操作系统"：管理 Skill 的生命周期（加载 → 校验 → 执行 → 卸载），提供沙箱隔离和错误恢复。

## 核心能力

| 能力 | 说明 | 状态 |
|------|------|------|
| 加载 | 从本地目录或远程源加载 Skill 及其依赖 | 🔮 P2 |
| 沙箱 | 限制 Skill 的文件系统/网络/进程访问 | 🔮 P2 |
| 编排 | 支持多个 Skill 的顺序、并行、条件组合 | 🔮 P2 |
| 观测 | 执行日志、性能指标、错误追踪 | 🔮 P2 |

## 技术方向

- 语言无关：Skill 可以是任何可执行脚本（Shell、Python、JS 等）
- 沙箱方案待 ADR 决策（Docker / Wasm / OS 级隔离）

## 状态

🔮 P2 阶段：接口定义 + 架构设计，P1 仅有定位说明。
